# Sonnet_link_checker
Simple Script to check links of all buttons on CTA's on your build

## once you have git on you machine, clone this repo using these instructions below:
```bash
git clone https://github.com/hernandezChristian9/Sonnet_link_checker
git checkout main
git checkout -b new-branch-name
git switch -c new-branch-name
```

## command on running the script
```bash
npx playwright test placeholder-links.spec.js
```
